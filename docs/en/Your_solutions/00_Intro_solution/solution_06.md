# Function Analysis: Local Extrema
**Function:** $f(x) = 3x^2 - 12x + 7$

---

## 1. Objective
To identify the **local maxima** or **minima** of the given quadratic function using calculus techniques.



---

## 2. Step-by-Step Derivation

### Step A: Find the First Derivative
To find the critical points, we first calculate the derivative $f'(x)$:
$$f'(x) = \frac{d}{dx}(3x^2 - 12x + 7)$$
**$$f'(x) = 6x - 12$$**

### Step B: Locate Critical Points
Set the first derivative to zero and solve for $x$:
$$6x - 12 = 0$$
$$6x = 12$$
**$$x = 2$$**

### Step C: Apply the Second Derivative Test
To determine if the point is a maximum or minimum, we find $f''(x)$:
$$f''(x) = \frac{d}{dx}(6x - 12)$$
**$$f''(x) = 6$$**

> **Test Rule:** > * If $f''(x) > 0$, the point is a **Local Minimum**.
> * Since $6 > 0$, our point at $x = 2$ is a minimum.

---

## 3. Final Coordinates
Plug $x = 2$ back into the original function $f(x)$ to find the $y$-value:
* $f(2) = 3(2)^2 - 12(2) + 7$
* $f(2) = 12 - 24 + 7$
* **$f(2) = -5$**

---

## 4. Conclusion
* **Local Minimum:** $(2, -5)$
* **Local Maximum:** None
* **Graph Shape:** The parabola opens upward because the leading coefficient (3) is positive.
