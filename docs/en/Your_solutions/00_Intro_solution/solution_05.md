# Mathematical Analysis: Vector Trigonometry
**Vector:** $\vec{A}$  
**Magnitude ($|\vec{A}|$):** $15$  
**Angle ($\theta$):** $60^\circ$

---

## 1. Objective
To decompose a two-dimensional vector into its horizontal ($A_x$) and vertical ($A_y$) components using trigonometric functions.



---

## 2. Theoretical Framework
For any vector $\vec{A}$ making an angle $\theta$ with the horizontal (x-axis), the components are defined by:
* **Horizontal Component ($A_x$):** $A_x = |\vec{A}| \cos(\theta)$
* **Vertical Component ($A_y$):** $A_y = |\vec{A}| \sin(\theta)$

---

## 3. Step-by-Step Calculation

### Step A: Calculate the Horizontal Component ($A_x$)
Using the cosine function:
$$A_x = 15 \times \cos(60^\circ)$$
* Since $\cos(60^\circ) = 0.5$:
* $A_x = 15 \times 0.5$
* **$A_x = 7.5$**

### Step B: Calculate the Vertical Component ($A_y$)
Using the sine function:
$$A_y = 15 \times \sin(60^\circ)$$
* Since $\sin(60^\circ) = \frac{\sqrt{3}}{2} \approx 0.866$:
* $A_y = 15 \times 0.866$
* **$A_y \approx 12.99$**

---

## 4. Final Vector Notation
The vector $\vec{A}$ can be expressed in unit vector notation as:
### **$$\vec{A} = 7.5\hat{i} + 12.99\hat{j}$$**

---

## 5. Summary Table
| Component | Formula | Calculation | Result |
| :--- | :--- | :--- | :--- |
| **Horizontal ($A_x$)** | $15 \cos(60^\circ)$ | $15 \times 0.5$ | **7.5** |
| **Vertical ($A_y$)** | $15 \sin(60^\circ)$ | $15 \times 0.866$ | **12.99** |

---

## 6. Conclusion
The vector extends further in the vertical direction than the horizontal because $60^\circ$ is closer to the y-axis ($90^\circ$) than the x-axis ($0^\circ$).
